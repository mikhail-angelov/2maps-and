# Navigation layout reference

Reference screenshots for the navigation layout (see issue #16).

- `yandex-navi-reference-1-on-route.jpg` — guidance on route: maneuver card, speed circles, bottom
  bar with remaining distance / arrival / remaining time and a traffic-coloured progress bar.
- `yandex-navi-reference-2-before-turn.jpg` — the same screen shortly before a maneuver: the card
  switches to metres ("10 м"), road name caption above the speed circles, bottom bar unchanged.

Source: screenshots of Yandex Navi (`ru.yandex.yandexnavi`) taken on 2026-10-10 while driving the
same Nizhny Novgorod route that issues #13–#15 were filed from. They are third-party material kept
here only as a design reference — remove them (and this folder) if the repository should not carry
them.
