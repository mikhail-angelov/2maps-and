# UI автомобильной офлайн-навигации

Дата: 2026-10-09. Статус: реализовано; `gradlew test` зелёный, проверка на телефоне и поведение `setAlternativeIdx` на реальных данных — отложены.
Ветка: `feature/brouter-offline-navigation`.

## Цель

Сделать спокойный, читаемый с первого взгляда экран автомобильной навигации:
следующий манёвр и расстояние до него, известное ограничение скорости,
направление движения, остаток пути и прогресс. Главный объект экрана — дорога
впереди автомобиля. Карта остаётся интерактивной.

Существующие данные и навигационная логика переиспользуются. Текущая большая
плашка и стандартные кнопки не задают дизайн: их компоновка, фон, типографика
и иконки перерабатываются. XML, ViewBinding и MapLibre сохраняются.

## Выбор маршрута перед стартом

После выбора пункта назначения сначала предлагаются основной маршрут и
до двух альтернатив. Навигация начинается только после нажатия «Поехали».
Если разных вариантов нет, показывается один маршрут с той же кнопкой старта;
дубликаты не выдаются за альтернативы.

- Карта показывает все найденные варианты целиком с учётом нижней панели.
  Выбранный маршрут яркий, остальные приглушённые; подписи времени у линий
  помогают сопоставить вариант на карте с карточкой.
- Нижняя панель на этапе выбора содержит компактные карточки вариантов:
  оценка времени и расстояние. Основной маршрут выбран по умолчанию. Не
  называть его «самым быстрым»: BRouter оптимизирует стоимость профиля,
  а не гарантированное время поездки. Для альтернатив можно показать
  разницу по времени относительно основного, если обе оценки доступны.
- Нажатие карточки или линии меняет выбор и выделение на карте. При тесном
  наложении линий выбор через карточки остаётся однозначным. Кнопка «Поехали»
  относится к выбранному варианту; крестик справа в нижней панели отменяет
  подготовку маршрута и текущие вычисления.
- Манёвр и лимит скорости до старта не конкурируют с выбором: верхняя
  карточка манёвра и дорожный знак появляются после «Поехали».
- Основной результат показывается сразу после его получения, без ожидания
  альтернатив. Для оставшихся вариантов — небольшой индикатор поиска.
  «Поехали» доступна сразу; её нажатие отменяет дальнейший поиск вариантов.
  Ошибка/тайм-аут альтернатив не удаляет уже найденный основной маршрут.
- Все варианты рассчитываются от одной зафиксированной исходной точки
  к одной цели и с одним автомобильным профилем. Новый пункт назначения
  отменяет прежний поиск; запоздалые результаты не меняют новый выбор.
- После «Поехали» запускается именно выбранный готовый маршрут, без повторного
  расчёта. При существенно изменившейся исходной позиции явно обновляется
  набор вариантов до запуска; не подменять выбранный путь незаметно.
- Во время движения автоматическое перестроение возвращает один маршрут
  и не открывает экран выбора, отвлекающий водителя.

### Получение альтернатив

В поставляемом ядре BRouter 1.7.9 есть `RoutingContext.setAlternativeIdx()`.
Использовать штатный механизм для основного варианта и индексов альтернатив,
а не создавать различия случайными промежуточными точками или сменой профиля.
Точное поведение индексов проверить на реальных дорожных данных при реализации.

Расчёты выполняются последовательно в существующем процессе `:routing`,
с сохранением отмены и ограничений памяти. Общий бюджет поиска вариантов —
30 секунд; основной результат не должен ждать полного бюджета. Полностью
совпадающие и практически одинаковые пути отфильтровываются по геометрии,
а не только по расстоянию/времени. Наличие трёх вариантов не гарантируется:
оно зависит от дорожной сети и результата движка. Сравнение геометрии должно
различать параллельные дороги и не требовать полного попарного сравнения точек
на длинных маршрутах.

## Компоновка

```text
┌────────────────────────────────────┐
│ ┌────────────────────────┐         │
│ │  ↱   350 м             │         │
│ │      Поверните направо │         │
│ └────────────────────────┘         │
│                                    │
│  ◯ 60                 компас       │
│                                    │
│             дорога                 │
│                │                   │
│                │                   │
│                ▲                   │
│                         следовать  │
│ ┌────────────────────────────────┐ │
│ │ 12 мин · 8,4 км · ≈14:32     × │ │
│ │ ━━━━━━━━━━━━━──────────────── │ │
│ └────────────────────────────────┘ │
└────────────────────────────────────┘
```

Схема показывает расположение, а не финальные пропорции и набор символов.
Крестик отмены находится **справа внутри нижней плашки**. В верхней карточке
крестика нет. Вокруг элементов — 12–16 dp свободного пространства; системные
панели и вырезы учитываются через insets.

### Визуальный язык

- Светлые почти непрозрачные карточки, тёмный контрастный текст, скругления
  около 16 dp и небольшая тень. Карта видна между карточками.
- Один акцентный цвет для манёвра и прогресса; он согласован с линией маршрута.
  Красный используется в ободке знака ограничения скорости.
- Расстояние до манёвра — главный текст сверху, 28–32 sp, полужирный.
  Команда — 16–18 sp. Остаток времени и расстояние снизу — 20–24 sp.
  Вторичная информация — 13–14 sp.
- Иконки манёвров — векторные, одного стиля. Использовать текстовые Unicode
  стрелки в итоговом UI не нужно: их форма зависит от шрифта.
- Интерактивная область каждой кнопки не меньше 48 × 48 dp, включая крестик.
  У кнопок есть подписи для TalkBack; цвет не является единственным сигналом.
- Размеры учитывают системный масштаб шрифта. Текст не перекрывает кнопки;
  длинная команда переносится максимум на две строки.

### Верхняя карточка манёвра

Компактная карточка у верхнего левого края, до примерно 280 dp шириной
на обычном телефоне. Слева крупная пиктограмма, справа расстояние и команда.
Поддерживаются существующие повороты, развороты, съезды, удержание стороны,
движение прямо и круговые перекрёстки. Для кольца показывается номер съезда,
если он есть в данных.

Расстояние считается вдоль маршрута существующим `RouteGuidance`, а не
по прямой. До 1 км показываются метры с разумным округлением, затем километры
с одним знаком после запятой. Около манёвра округление становится точнее.
После прохождения переключаемся на следующий манёвр; существующий гистерезис
сохраняется. Когда промежуточных манёвров нет, показывается финиш и расстояние
до него. Название улицы и полосы движения не выдумываются: этих данных
в текущей модели нет.

### Ограничение скорости

Отдельный круглый дорожный знак около 56 dp у левого края под карточкой
манёвра: белый фон, красная обводка, крупное чёрное число. Единицы — км/ч,
доступное описание уточняет, что это ограничение, а не скорость автомобиля.

Источник — уже разобранный числовой `maxspeed` текущего участка, включая
ограничения по направлению. При неизвестном значении знак скрывается,
не показывает ноль и не переносит лимит предыдущей дороги. Скорость профиля
маршрутизации не становится ограничением. При потере достоверного положения
знак скрывается до подтверждения участка; в предпросмотре разрешён только
  лимит участка у показанной точки. Отдельная подпись Route preview не выводится.
Предупреждения о превышении скорости в эту работу не входят.

### Нижняя плашка

У нижнего края — компактная карточка на доступную ширину, ориентировочно
64 dp высотой при стандартном шрифте. В одну строку: оставшееся время
и расстояние, приблизительное время прибытия только при наличии места. Справа: кнопка ×,
отделённая от текста отступом. Внизу карточки — тонкая полоса прогресса.

- Остаток берётся из `NavigationState.remainingMeters/remainingSeconds`.
- Время — оценка существующего движка, без пробок; показывать «≈» у прибытия.
  Если оценка времени отсутствует, остаётся расстояние, фиктивного ETA нет.
- Прогресс: пройденное расстояние по геометрии / полная длина этой же геометрии,
  ограниченное диапазоном 0–100%. Не смешивать длину геометрии с отдельной
  оценкой длины BRouter. После перестроения начинается прогресс нового маршрута.
- Нажатие × немедленно завершает навигацию и отменяет текущий расчёт.
  GPX-запись продолжает работать, если была включена. Диалог подтверждения
  для этого обратимого действия не нужен.
- При прибытии показать «Вы на месте» и завершённый прогресс; крестик остаётся.

## Карта, лидирование и направление

Под «лидированием» понимаются вид дороги впереди, ориентация камеры по движению
и стрелка положения. Это не инструкция о полосе движения.

- В режиме следования маркер находится примерно на 65–70% высоты свободной
  области карты между верхней и нижней карточками. Впереди остаётся больше
  места, чем позади. Это задаётся padding камеры, с пересчётом при повороте
  экрана и изменении размеров карточек.
- Карта ориентируется по достоверному курсу движения. Использовать свежий
  GPS bearing при движении быстрее 3 м/с и допустимой точности курса.
  При его отсутствии можно использовать направление между достоверными
  позициями с достаточным смещением. Сырые скачки координат не меняют курс.
- На остановке сохраняется последняя стабильная ориентация. При первом
  запуске без надёжного курса сохраняется текущий поворот карты; направление
  маршрута не выдаётся за фактическое направление автомобиля.
- Переходы курса учитывают кратчайший поворот через 0°/360°, без полного оборота.
  Начальный вариант — плоская карта без наклона и автоматической смены масштаба.
- При известном курсе маркер — стрелка, ориентированная относительно карты.
  Без курса — нейтральная точка. Маркер не скрывается под карточками.
- Перемещение/вращение карты пользователем приостанавливает следование до
  нажатия кнопки возврата. Автоматического возврата по таймеру в навигации нет.
  Возврат восстанавливает лидирование. Компас позволяет осмотреть карту
  севером вверх, также приостанавливая поворот по движению.
- Полный маршрут виден при первоначальном предпросмотре; во время движения
  камера следует за автомобилем. Новый расчёт не вызывает постоянных скачков
  между обзором всего маршрута и положением автомобиля.
- Пройденная часть линии отображается приглушённо, оставшаяся — акцентно.
  Разделение использует существующую проекцию на геометрию, обновляется только
  подтверждённым прогрессом и не затрагивает записываемый GPX-трек.

## Состояния и слабый GPS

| Состояние | Представление |
| --- | --- |
| Нет навигации | Навигационные карточки и знак скрыты; обычные элементы карты восстановлены. |
| Нет исходной позиции | Компактное сообщение и действие включения определения положения; крестик доступен снизу. |
| Первый расчёт | Сообщение «Строим маршрут…», компактный индикатор; отмена снизу. |
| Выбор перед стартом | Основной маршрут и доступные альтернативы на карте и в нижней панели; «Поехали» для выбранного, крестик справа. |
| Маршрут без точного GPS | Маршрут и его оценки доступны, без подписи Route preview; GPS не блокирует карту. |
| Движение | Манёвр, актуальный лимит, остаток и подтверждённый прогресс. |
| Потеря GPS после движения | Подпись «Позиция не обновляется»; сохраняются последний подтверждённый остаток и прогресс, маршрут не сбрасывается к началу. Не показывать устаревшие детали как актуальные; ETA не пересчитывать от текущих часов. |
| Перестроение | Компактная подпись «Перестраиваем…», предыдущая линия остаётся до результата. |
| Ошибка | Короткое сообщение и нужное действие Retry/Road data; при наличии старого маршрута отмечается его неактуальность. Крестик доступен. |
| Прибытие | «Вы на месте», завершённый прогресс и крестик. |

Существующие требования к хорошему GPS для автоматического прогресса, прибытия
и перестроения сохраняются: точность до 50 м, возраст до 15 с. Планирование
по показанной на карте точке по-прежнему не требует точного GPS. Обнаружение
устаревшего положения должно работать и при полном прекращении новых событий,
а не только при поступлении плохой позиции.

## Сосуществование с остальными элементами

Во время навигации основные кнопки карты располагаются у правого края между
карточками. Не нужные для движения быстрые действия скрываются; меню остаётся
доступным и не перекрывает верхнюю карточку. Кнопка возврата на позицию находится
над нижней плашкой. Панель статистики GPX-записи располагается выше неё либо
сворачивается в небольшой индикатор записи; сама запись не останавливается.

В горизонтальной ориентации верхняя карточка остаётся у левого края,
нижняя панель становится ниже за счёт компактной компоновки. При обычном
масштабе шрифта остаётся минимум половина высоты карты между карточками.
На узком экране сначала сокращается вторичная информация, а не область
манёвра, маркера или кнопка отмены.

## Реализация без лишних абстракций

1. Вынести оформление, форматирование и действия карточек из `MapFragment`
   в небольшой `NavigationPanel` с `render(NavigationState)` и callbacks.
   XML и векторные drawable переиспользуются/перерабатываются по дизайну.
2. `NavigationViewModel` остаётся владельцем состояния маршрута и прогресса.
   При необходимости добавить только подтверждённый прогресс и признак
   устаревания позиции, чтобы UI не вычислял их повторно из GPS.
3. Камера и MapLibre-слои остаются в существующих владельцах. Курс и фильтрация
   получают один источник, чтобы камера и стрелка не противоречили друг другу.
4. Разделение линии выполняется `RouteLayerManager`; не вводить второй matcher.
5. Обновить debug/Robolectric-разметку и существующие UI-проверки вместе
   с основной разметкой. Новые фреймворки, Compose и DI не нужны.
6. Расширить существующий `RoutingEngine` и локальный IPC только передачей
   индекса варианта; подготовку набора, выбранный вариант и переход
   «предпросмотр → движение» хранить в `NavigationViewModel`. Не добавлять
   второй движок или отдельный сервис для альтернатив. На этапе выбора
   прогресс, прибытие и автоматическое перестроение ещё не запускаются.

## Приёмка

- До старта предлагаются действительно разные доступные маршруты, максимум
  три. Карточки и линии согласованно выделяют выбор; «Поехали» запускает
  именно его. Один маршрут, отсутствие альтернатив и ошибка их расчёта
  оставляют возможность старта. Отмена и смена цели прекращают старый поиск.
- На портретном и горизонтальном экране манёвр, знак скорости, нижняя плашка
  и элементы карты не перекрываются; маркер и дорога впереди видны.
- На 320 dp ширины и увеличенном шрифте 1,3× все основные данные читаемы,
  крестик имеет область нажатия 48 dp и расположен справа в нижней плашке.
- Проверены левый/правый поворот, разворот, кольцо с номером съезда и финиш;
  следующий манёвр и расстояние обновляются при прохождении.
- Известный лимит отображается дорожным знаком, неизвестный скрывается;
  переход на участок без лимита не оставляет старое число.
- Остаток и линия прогресса изменяются при достоверном движении. Пройденная
  часть маршрута приглушена. GPS-скачок не разворачивает камеру.
- Потеря GPS не блокирует карту, не обнуляет прогресс и не возвращает полный
  остаток; восстановление продолжает навигацию. На остановке курс стабилен.
- Жест приостанавливает следование; кнопка возврата восстанавливает его.
- Крестик работает во время расчёта, движения, ошибки и прибытия. Запись трека
  продолжается после отмены навигации.
- Обязательная проверка: `env JAVA_HOME=/Library/Java/JavaVirtualMachines/zulu-17.jdk/Contents/Home ./gradlew test`.
  Затем сборка APK и визуальная проверка на реальном телефоне, когда он снова
  подключён. Пока телефон в поездке, установка и телефонная проверка отложены;
  результат не объявляется проверенным на устройстве.

Голос, полосы движения, пробки, превышение скорости, фоновая навигация,
новый GPS-фильтр всего приложения и смена движка маршрутизации вне этой работы.
